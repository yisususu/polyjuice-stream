# Project conventions

- Write documentation, code comments and examples in English. Conversation with the user may remain in Chinese.
- This project is a small Go mock LLM response server. Follow the scope and confirmed decisions in `docs/design-v0.1.md`.
- Keep planned and implemented features clearly distinguished. Command examples are proposals until implementation exists.
- Keep the README short; put design detail in `docs/`.
- Keep source packages under `src/`, tests under `tests/`, and use synthetic example data.
